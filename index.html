测算依据与使用边界

本工具用于容量规划与成本预估：先估算模型 Decode 阶段的算力上限，再用工程效率折算为可用吞吐；业务口径则按稳定 QPS 与平均输出 Token 计算。对外服务能力必须以同一硬件、同一模型精度和真实负载压测为准。

NVIDIA NIM · Metrics ↗TPS 应与 TTFT、ITL 等时延指标一起解释，不以单一 TPS 承诺服务能力。
NVIDIA NIM · Parameters ↗并发、批处理、输入/输出长度与队列共同影响实际吞吐。
vLLM · Per-request Metrics ↗建议压测时记录 Aggregate Output TPS、TTFT、队列时间与平均 ITL。
示例模型参数参考公开模型卡：DeepSeek-V3（671B 总 / 37B 激活）、Qwen3-235B-A22B（235B 总 / 22B 激活）。其他预设仅用于快速估算，部署前请以模型卡、权重文件和实际精度确认。
