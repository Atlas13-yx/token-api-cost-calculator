测算依据与使用边界

本工具用于容量规划与成本预估：容量模式从硬件上限推算可用吞吐；QPS 模式从业务需求反算单套等效工程效率与理论最少配置。对外服务能力必须以同一硬件、同一模型精度和真实负载压测为准。

NVIDIA NIM · Metrics ↗TPS 应与 TTFT、ITL 等时延指标一起解释，不以单一 TPS 承诺服务能力。
NVIDIA NIM · Parameters ↗并发、批处理、输入/输出长度与队列共同影响实际吞吐。
vLLM · Per-request Metrics ↗建议压测时记录 Aggregate Output TPS、TTFT、队列时间与平均 ITL。
DeepSeek · V4 官方说明 ↗V4-Flash 为 284B 总参数 / 13B 激活；V4-Pro 为 1.6T 总参数 / 49B 激活。
Moonshot AI · Kimi K3 ↗官方开放权重：2.8T 总参数 / 104B 激活。
Moonshot AI · Kimi K2.7 Code ↗官方模型卡：1T 总参数 / 32B 激活。
